## <samp>bluetooth config- </samp>

```bash
first install `bluez` & `bluez-utils
-----------------------------------------
systemctl enable bluetooth.service
systemctl start bluetooth.service
  bluetoothctl
  scan on

  pair mac_address
  trust mac_address
  connect mac_address
  quit 
 ```
